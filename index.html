Generator vektor prosedural: semua bentuk digambar dari kode, jadi file yang kamu unduh adalah SVG asli, bukan gambar AI. Tinggal atur tema, palet, dan seed, lalu unduh dan upload ke situs stok sebagai vektor. Jalan sepenuhnya offline, tanpa API key.
